# Require explicit codebase registration

Code Inquiry and Delegation may operate only on Registered Codebases rather than discovering or accepting arbitrary filesystem paths. Each registration fixes the repository path, remote, production branch, permitted read scope, isolated-worktree location, verification commands, and any Deployment Contract. This adds deliberate enrollment work but makes authority reviewable, prevents conversational path injection from expanding scope, and gives every code excerpt, change, test, and deployment stable provenance.
