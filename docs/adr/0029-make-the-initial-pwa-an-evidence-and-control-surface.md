# Make the initial PWA an evidence and control surface

The initial PWA will provide authentication and recovery setup, Durable Task lists and status, Evidence Records, and only the narrow visual controls required by delivered vertical slices. Each task begins with a concise status and conclusion and then presents a chronological visual timeline whose bounded excerpts, diffs, and verification details can be expanded; material rejected by disclosure filters is never delivered to the browser. The service worker may cache only the static application shell and public assets, never authenticated API responses or task, evidence, policy, or credential data, and it shows an explicit unavailable state offline. General typed task initiation is deferred to its own vertical slice after the first three telephone slices and before WebRTC.
