# Separate brokered secrets from manifest disclosure

The default production path is Brokered Secret Use: an Operations Broker consumes a credential and returns a bounded sanitized result without exposing the secret to either the Voice Agent or a Subagent. A Secret Execution Manifest is a distinct, intentionally weaker path for a development or service credential that a restricted Subagent genuinely must receive; its activation or revision requires a Fresh Passkey Action and is immutably recorded with every launch. Vaulted Agent may implement manifest resolution, but its manifests constrain blast radius rather than conceal credentials. Production database, SSH, vault-manager, and broad cloud credentials are initially forbidden from manifests and remain behind typed brokers unless authenticated policy editing changes that boundary.
