# Stage application authority by vertical slice

Application enrollment grants only the capabilities required by the current vertical slice. Bountywell initially receives the read capabilities required for its health inquiry; restart authority is added later through a separate Fresh Passkey Action for the guarded outage drill. Keeplore remains unenrolled until its working tree is reconciled and its deployment foundation is established. This prevents a future slice's authority from becoming ambient before its controls and acceptance path exist.
