# Report Deployment Authority Drift without failing a Promotion

Automatic Promotion never replaces root-pinned orchestration, systemd definitions, or AppArmor profiles, and that boundary is what stops a merged commit from expanding root authority on the Agent Host. Every Promotion Attempt therefore compares the Release left serving against the Pinned Deployment Authority and records the diverging paths, naming the attended `./ops/upgrade-agent-host-deployment-authority.sh` as the action that applies them. Deployment Authority Drift is a normal state and settles nothing: it does not fail the Promotion Attempt, count toward consecutive failures, or open the Deployment Circuit Breaker. It is reported through the promotion metrics beside `voice_agent_promotion_circuit_open` and through the Promotion's Evidence Record, so an owner can tell a fully live Release from one that is live except for its root-pinned parts without a root terminal.
