# Use a GitHub App and verified Human Merge events

The Voice Agent will use a dedicated least-privilege GitHub App installed only on Registered Codebases, with the repository-content and pull-request permissions needed to push non-production branches and open or update pull requests, plus read access to checks, but no repository-administration or ruleset-bypass authority. Registration requires production-branch rules that require pull requests and block force pushes and deletion. A separate deployment service verifies each webhook's HMAC-SHA256 signature and unique delivery identifier, accepts only a Human Merge into the registered production branch, queues Promotion of the exact merge commit, and periodically reconciles GitHub state so missed deliveries do not silently skip deployments.
