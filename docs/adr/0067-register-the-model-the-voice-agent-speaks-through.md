# Register the model the Voice Agent speaks through

The model the Voice Agent synthesises with was a literal written out twice — once for the conversation and once for the fixed text the authentication worker plays — while only its voice was configurable, so when that gateway stalled on 2026-08-24 there was no way to move off it without editing code, merging, and promoting a release. The remedy is a Recognized Synthesis Model, the counterpart of the Recognized Speech Model ADR-0057 introduced: a set this system carries, each entry naming its model, the provider identity recorded against the synthesis stage in evidence, and the voice that provider names its speakers by. `VOICE_AGENT_TTS_MODEL` chooses one, an absent setting selects `inworld/inworld-tts-2` as production runs today, and a setting naming anything outside the set ends the worker process at start rather than delivering its refusal as a provider error in the middle of a call.

A voice belongs to its own provider, so the voice setting is not separable from the model. An entry carries a default voice only where this system has a researched choice for one: `inworld/inworld-tts-2` carries Sarah, and `cartesia/sonic-3.5` carries none, because Cartesia names its speakers by identifier and `research/2026-08-11-livekit-pipeline-providers.md` designates none. Selecting that entry without naming a voice is refused at start alongside a mistyped model, because a model with no voice to speak in fails the same way and at the same moment. The research note names the Cartesia generation by its dated pin `cartesia/sonic-3.5-2026-05-04`; only `cartesia/sonic-3.5` is a LiveKit Inference model ID, the same resolution ADR-0057 made for `assemblyai/u3-rt-pro`, and it is not the `sonic-latest` alias that note refuses.

Nothing switches provider during a call. ADR-0049's single Bounded Provider Retry, ADR-0044's fail-closed ending, and ADR-0052's attribution of a fault to the stage that raised it are unchanged, and `CONTEXT.md` still lists automatic provider failover as vocabulary to avoid. The agents framework's own server-side TTS fallback is deliberately left unconfigured for the same reason. What changes is that the provider recorded against the synthesis stage is read from the entry in use rather than fixed as `inworld`, so an operator who moves off a stalled gateway is not reading `provider=inworld` against a fault a different provider raised.

## Consequences

The provider recorded for a synthesis fault now follows the configured entry, and the operational rollup folds a provider it does not enumerate into `other` rather than misreporting it, so moving to the researched fallback needs no schema migration. The entry's model also appears on the provider-failure and speech-timing events for the synthesis stage, which is what lets a recorded `stage=tts` fault be read against the model actually in use; the model an event carries is now the configured model of whichever speech stage raised it, and a stage this system configures no speech model for still carries none.

The setting reaches every speech any provider synthesises: the conversation, the fixed text the authentication worker plays, and the completion callback. The prerecorded provider-failure response is unaffected, because it is recorded audio this system plays itself — which is what keeps a stalled provider ending the call the way it does today rather than through a second provider.

`VOICE_AGENT_TTS_VOICE` gains one refusal it did not have: an empty value ends the process at start rather than being read as an unset one. A voice setting present but empty is a misconfiguration of exactly the kind this decision moves in front of a Promotion Attempt's health verification, and silently falling back to the entry's default would speak in a voice the unit does not name.

The Inworld `delivery_mode="STABLE"` the research note designates is still not set, as it was not before this decision; the entries carry model, provider, and voice only. Registering provider options is what the recognition set does, and doing it here would change how production speaks under cover of making it configurable, which is the unrecorded model change this set exists to prevent.
