# Assess repository policy with the agent's own authority

The Voice Agent assesses a Registered Codebase's production-branch rules and GitHub App installation only from what its own credentials can observe: an App JWT for the installation's granted permissions and repository selection, and an installation token for the repository list and the rules active on the production branch. It acquires no repository-administration permission to widen that view, and an unobserved or stale observation stays unassessed rather than assumed satisfied. One boundary lies outside that authority entirely: GitHub discloses a ruleset's bypass actors only to an actor with write access to the ruleset, which the App must never hold, so the absence of a disclosure proves nothing and the agent must not treat the branch as clean because it could not look. The owner reads the bypass actors with their own authenticated account and attests the result into the same append-only journal, and until they do, the assessment records the boundary as unattested.
