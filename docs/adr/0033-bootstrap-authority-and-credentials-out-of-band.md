# Bootstrap authority and credentials out of band

Initial authority will be established by a short-lived, single-use Bootstrap Code generated through the owner's existing SSH access and entered at `voice.stephens.page`. Bootstrap enrollment is permanently disabled after two passkeys and Recovery Codes exist; later loss of authenticators follows offline recovery rather than reopening bootstrap. A separate human-run setup wizard places LiveKit, Telnyx, AssemblyAI, OpenAI, Inworld, Resend, and GitHub App credentials into distinct root-owned sources and exposes each service only to its required credentials through systemd. Provider credentials are never accepted through voice, the PWA, repository files, shell history, or general Subagent environments.
