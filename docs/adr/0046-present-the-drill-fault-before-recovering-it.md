# Present the drill fault before recovering it

The Bountywell Outage Drill recovers only from a fault report the drill controller has presented to the Voice Agent: stopping the registered unit opens no diagnosis Operation, so no worker poll and no Task Confirmation can complete a drill the Voice Agent was never told about, and an affirmative Task Confirmation recovers only that presented unavailable-API drill. The fault is injected only while a live Telephone Session carries the owner, because an asserted request flag is not evidence of availability. Arming, proving, presenting, and injecting run on the already-enrolled Standing Autonomy Policy; only enrolling the restart capability expands authority and needs a Fresh Passkey Action. After verified recovery the Agent Host must report the independent timer gone before the drill concludes, and the owner receives the agreed completion report rather than only a Durable Task page.
